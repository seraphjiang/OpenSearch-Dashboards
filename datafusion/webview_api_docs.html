🔌 Plugin APIs

OSD provides rich plugin APIs for extending functionality:

  • Workspaces: Multi-tenancy and workspace management
  • Data Source Management: Connect to multiple OpenSearch clusters
  • Query Enhancements: Advanced search capabilities (PPL, SQL)
  • Application Config: Dynamic configuration management
  • Console: Interactive OpenSearch query console
  • Telemetry: Usage analytics and metrics
  • Chat/ML: AI-powered interactions via AG-UI
  • Data Importer: Import data from various sources
  • Visualizations: Timeline, TSVB, Region Maps
