## 🚀 How to Use

### Quick Start - Web View (Easiest!)
1. Open `webview-api-docs.html` in your web browser
2. Navigate through the beautiful interface with:
   - Statistics dashboard
   - Quick navigation
   - Embedded Swagger UI
   - Download links for all formats

### Interactive Swagger UI
1. Open `swagger-ui.html` in your web browser
2. Browse API endpoints organized by tags
3. Click "Try it out" to test endpoints directly
4. View request/response schemas and examples

### ReDoc Documentation
1. Open `swagger-api-doc.html` in your web browser
2. Search and browse through all API endpoints
3. View detailed schemas and examples
4. Download the OpenAPI spec

### PDF & Word Documentation
- **PDF:** Open for offline reading, print, or share with team
- **Word:** Edit and customize documentation as needed
- Both formats contain the same comprehensive content

### Import to API Tools
1. Import `openapi-spec.yaml` into:
   - Postman: File → Import → OpenAPI
   - Insomnia: Create → Import → From File
   - API clients supporting OpenAPI 3.0
